# Lolumen for Hearthstone: desktop app downloads

This repository holds only the installers for the Lolumen desktop app. Each release is one version. The app's source code isn't here.

**Download:** [www.lolumen.com/desktop](https://www.lolumen.com/desktop)

The app checks this repository's releases for updates and installs them itself.

It reads only the log files Hearthstone writes on your computer. It never reads the game's memory, never sends input to the game, and never shows anything the game keeps hidden.
